# Changelog

## 0.2.0 — reliability release

- Stable raw-tail probe acceptance instead of one-time threshold crossing.
- Signed residual-decay scoring.
- Explicit verification and failure states.
- Observed safe intervals backed only by successful sampled points.
- Automatic preflight, fail-fast runtime errors, safe resume, correct seed reuse, scheduler argument separation, and deterministic fake-pw.x integration tests.

Real Quantum ESPRESSO benchmark result datasets are intentionally outside this release.
